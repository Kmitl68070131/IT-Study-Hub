IT-Study-Hub — อัปขึ้น GitHub แบบอัตโนมัติจากคอมพิวเตอร์ Windows
======================================================

สถานะ: GitHub connector ในแชตอ่าน repo ได้ แต่ถูกปฏิเสธการเขียน (HTTP 403)
ชุดนี้จึงมีไฟล์ .bat สำหรับทำงานบนคอมพิวเตอร์ของคุณและใช้ GitHub sign-in ของคุณเอง

วิธีที่ง่ายที่สุด
1. ติดตั้ง Git for Windows และ Python 3 (และแนะนำ Node.js เพื่อรันทดสอบ)
2. แตก ZIP นี้ลงโฟลเดอร์ เช่น Desktop\StudyHubUpload
3. ดับเบิลคลิกไฟล์ "อัปขึ้นGitHub.bat"
4. หาก Git เปิดเบราว์เซอร์ ให้ลงชื่อเข้าใช้ GitHub ด้วยบัญชี pakk49
5. สคริปต์จะ clone repo main, ใส่ Final บท 7–12, เพิ่ม Midterm/Final, ตรวจข้อสอบ และ push ขึ้น main
6. เปิดเว็บ https://pakk49.github.io/IT-Study-Hub/ หลัง deploy GitHub Pages เสร็จ

สิ่งที่ได้
- Multimedia Final บท 6–12 (บท 6 เดิม + บท 7–12)
- เนื้อหาและแฟลชการ์ด พร้อมคำศัพท์และความหมาย
- ข้อสอบรายบทพร้อมเหตุผล
- ข้อสอบรวม Final 60 ข้อ พร้อมระบบแก้ข้อผิด
- Midterm แยกเป็นอีกหมวด รอสไลด์กลางภาค (ไม่ได้แต่งข้อสอบสมมติ)
- README พร้อมลิงก์กดเปิดหมวด

ข้อควรทราบ
- สคริปต์อาจเปิดหน้าต่างยืนยัน GitHub; คุณต้องล็อกอินเอง
- ไม่เก็บรหัสผ่านหรือ access token ไว้ในไฟล์
- ไม่ force-push และไม่ลบไฟล์วิชาอื่น
- หากไม่ต้องการใช้สคริปต์อัปโหลด ให้ใช้ "อัปเดตเว็บ.bat" กับ repo ที่ clone เอง แล้ว git push
